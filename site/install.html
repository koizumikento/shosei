shosei

Japanese publishing workflows for EPUB, PDF, Kindle, and print handoff.

Overview Install Usage Config Quickstart Contributing GitHub

Install

tag 付き GitHub Release では CLI archive、platform 別 VSIX、universal fallback VSIX を配布し、Homebrew / Scoop 向け manifest は package repository publish が通ったときに更新します。platform 別 VSIX は同じ version の CLI を内包し、Open VSX または VS Code / Cursor の手動 install / update で利用できます。

Requirements

  • macOS では Homebrew、Windows では Scoop、または source install 用の Rust toolchain と `cargo`
  • 対象 platform: macOS / Windows / Linux

Install with Homebrew (macOS)

brew tap koizumikento/stray-tools https://github.com/koizumikento/stray-tools.git
brew install koizumikento/stray-tools/shosei

Update with Homebrew (macOS)

brew update
brew upgrade koizumikento/stray-tools/shosei

Install with Scoop (Windows)

scoop bucket add stray-tools https://github.com/koizumikento/stray-tools
scoop install stray-tools/shosei

Install from source

リポジトリを clone して `shosei` バイナリを install します。

git clone https://github.com/koizumikento/shosei.git
cd shosei
cargo install --path crates/shosei-cli

Release archives

GitHub Release には x86_64-unknown-linux-gnu, x86_64-apple-darwin, aarch64-apple-darwin, x86_64-pc-windows-msvc の CLI archive と、対応する linux-x64, darwin-x64, darwin-arm64, win32-x64 VSIX が載ります。platform 別 VSIX は同じ release version の CLI を同梱します。

Update the extension

Open VSX 対応 editor では現在の platform に合う VSIX が選ばれ、拡張更新時に bundled CLI も同時に更新されます。手動 install / update では GitHub Release の shosei-vscode-<version>-<target>.vsix を使います。target suffix のない VSIX は bundled CLI を持たない universal fallback です。

  • Cursor: Extensions: Install from VSIX...

Smoke check

インストール前に CLI surface を確認するだけなら、次で十分です。

cargo run -p shosei-cli --bin shosei -- --help

What gets installed

GitHub Release archive は release asset の shosei binary を使います。Homebrew / Scoop は release 後に package repository publish が成功した場合、その archive を参照する formula / manifest から導入できます。

cargo install --path crates/shosei-cli は workspace 内の CLI crate から shosei バイナリを build して install します。platform 別 VSIX は同じ version の CLI を内包し、Pandoc、Chromium、epubcheck、qpdf、Kindle Previewer などの外部 toolchain は shosei doctor で別途確認します。
